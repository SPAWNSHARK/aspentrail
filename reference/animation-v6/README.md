# Wayfarer V6 procedural motion library
Four JSON libraries contain sampled local Euler rotation offsets, 25 samples per clip. adapter.mjs converts them to Three.js quaternion animation clips on actual scene nodes. No external dependencies beyond host Three.js. Run node --test test.mjs. The tests validate data, not visual quality or integration.

Integrate with V5 Animator: call buildClips(THREE, library, semanticJointMap), merge by clip name with existing GLB clips (prefer existing authored clips until visual comparison), configure each action with configureAction. Bind actual Object3D nodes, not names alone; inspect missing joints. felineMap is a provisional mapping for V2 cats; confirm front/rear orientation visually. Other rigs were not available locally; map manually and verify local axes and rest pose. Do not animate the physics root. All motions are in place; V5 owns translation. Chair and social contact require scene anchors and IK, not included. Jump/Fall/Land need event-driven transitions; V5 currently does not emit a Land clip automatically. Some motions share templates; these are starting poses, not polished animation. No new GLBs, audio, full IK or live Safari testing. Do not deploy without integration and visual review. Keep V2, V3, V5; discard V4.
