# Wayfarer Hull Fit Kit v0.3

Supersedes v0.2 **prototype kit only**. Keep the original uploaded exterior and live project files. This package includes 24 GLBs, an updated coordinate contract, build scripts, validation manifest, and a blueprint PDF based on actual model/room coordinates. Procedural blockout geometry, not final textures.

Load `models/Wayfarer_Dual_Deck_Assembled.glb` at the origin. It contains both decks, split-level atrium, aft walkways, curved stairs, physical brain and reactor, hinged dock and Firefly. Load `models/Wayfarer_Exterior_Mobile_Animated_Jaw.glb` separately at the same origin to see the original split exterior. The room GLBs and deck assemblies use ship-space coordinates, so do not stack the individual rooms on the complete assembly. `Aft_Transition_Upper.glb` and `Aft_Transition_Lower.glb` supply the new continuous aft floor when loading separate rooms. `Firefly_Interior.glb` is a separate local-space cabin reference. Hide the exterior and `Ceiling_*` nodes for a cutaway. `source/Wayfarer_Original_Mobile.glb` retains normalized source geometry, not pre-scaled; do not scale the other assets again.

`integration.mjs` is a standalone Three.js example for both jaw clips, launch/recovery and cutaways. Requires a compatible THREE, GLTFLoader and animation loop. It has not been runtime-tested or integrated into the existing multi-page A-Frame game. Navigation, collisions, pressure seals, clearance and shader mapping need integration work. `MASTER_SPEC.md` and `layout.json` govern room geometry. `manifest.json` contains parsed assets and area comparisons, and `hull_fit_report.txt` shows boundary sample results. Run build_assets.py and build_hull_jaw.py with Python, numpy, shapely, trimesh and Pillow to regenerate; verify_and_document.py needs matplotlib and can compare the old layout if present.

## Atrium revision
`Split_Hall_Upper.glb` and `Atrium_Lower.glb` are individual shared-coordinate modules. The assembled model includes them already. `navigation.json` provides checked circulation waypoints, room thresholds, and tagged curved-stair links; not a complete NPC pathfinding implementation. `atrium_validation.json` reports mesh-level floor checks. Run `validate_atrium.py` after rebuilding, then `verify_and_document.py`. Do not reuse v0.2 corridor collision bounds: the central opening must be treated as non-walkable on the upper level. Keep the original exterior; the lower core clearance conflict remains.
