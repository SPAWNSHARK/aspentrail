# SS Wayfarer — Complete Architectural Overhaul V8
Supersedes V7; includes its complete decking kit and textures. Additive to V2, V3, V5, V6. No automatic repository edits. Back up first.

Import createArchitectureKit from architecture.mjs with the host THREE instance and deployed texture directory URL ending in /. All dimensions in meters. Existing scene layout and collision remain authoritative. The screenshot shows two decks and an atrium; preserve these. Measure actual scene spans before placing anything.

API: deck(w,d,kind,tile), railing(length,height), stairs(width,steps,rise,tread), guide(length) are inherited from V7. Deck is horizontal centered at origin, y=0; railing along X; stairs ascend +Z. Kinds corridor, bridge, lounge, engineering, stairs. Wall(w,h,kind) is centered along X, faces +Z, starts at y=0. Ceiling(w,d) is centered on X/Z, underside at y=0. Skylight(w,d,rise,{showGlass,ribSpacing}) is a curved canopy rising above y=0, length along Z. Portal(w,h) is an open frame, not a door; threshold(w) is a shallow visual strip. Rotate and position groups to match the existing architecture. Wall and ceiling modules must be split around doors, windows and atrium openings. Never place a solid deck across the atrium. Preserve door animation and collision, stairs and NPC navigation. Remove old visual meshes only after checking alignment; avoid z-fighting. Keep existing glass/sky rendering if replacement conflicts. skyMotion(mode,seconds) returns offset/stretch/opacity parameters for existing star renderer; modes docked/orbit/cruise/hyperspace. Host must connect them; no sky shader included.

Use neutral white key/ambient lighting and restrained copper accent lights; avoid blanket exposure changes. Emissive strips do not illuminate surroundings automatically. Use existing light budget; no screen-space reflections. Glass uses approximate alpha blending; disable canopy glass or replace railing glass if sorting/performance is poor. Reuse materials, merge static geometry where practical, dispose per-deck cloned textures when unloading. All 21 maps are procedural base/roughness/normal maps; no separate metallic or AO maps. Geometry is runtime Three.js, not GLB. No new audio, planet imagery, actual animated doors or collision engine. Room-specific wall variants beyond lounge base trim require host styling. Test first/third person, both decks, door clearance, stair alignment, NPC paths, lighting, texture loading and frame rate on iOS. No live repository or browser test performed.
