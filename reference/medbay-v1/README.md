# SS Wayfarer Medbay V1
Additive lower-deck module, provisional 8 x 7 x 3 m. Read Medbay_Integration_Guide.pdf. 23 modular GLBs and one static assembled preview. Runtime uses modular GLBs. Do not mount both versions simultaneously. Host must provide THREE, GLTFLoader and callbacks. `baseURL` must have a trailing slash. `update(dt)` expects seconds. `pick(raycaster)` returns an interaction ID; only call it for a nearby player and a ray not occluded by room geometry, as host interaction rules must enforce line of sight and reach. `pod_button` starts recovery; `privacy_button` toggles screen; direct `canopy` click toggles lid when idle. Event hooks support custom HUD and inventory. Collision boxes are world-space AABBs; host must implement physics. Default droid uses simple local waypoints and has no skeletal clips; choose hostDroid for production navigation. This pack does not add a deck or alter existing rooms. Connect existing game health to state.setHealth and job_end event; fictional game logic only. No external runtime dependencies beyond the host Three.js environment. See validation.txt for the state tests and GLB decode checks.
