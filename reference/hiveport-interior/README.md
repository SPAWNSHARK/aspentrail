# HIVEPORT — Argo Station / Deck 5
Prototype implementation kit for SS Wayfarer (Three.js, GLB 2.0, meters, Y-up, +Z toward entrance). Hiveport is the proposed final name in the concept; The Resin Spire is the main bar.

## Load into the game
1. Copy the directory into your site's assets, keeping folder paths. Use a local server or GitHub Pages, not file://.
2. Import `createHiveport` from `systems/three-integration.mjs`. Pass your existing `THREE`, `GLTFLoader`, scene, and the asset directory as `base` (with trailing slash). Use `playerPosition: () => camera.position` or the player collision body's world position.
3. Call the returned object's `update(deltaSeconds)` in your frame loop. Start with 16–24 NPCs on mobile. The supplied navigation test used 32.
4. For room streaming, load the nine individual room GLBs instead of `Hiveport_complete.glb`; the individual room files are already positioned in global coordinates. Do not load both. `layout.json` is the matching geometry/collision/interaction data; integrate these same obstacle footprints into the player's collision controller.
5. Use an environment map (PMREM or existing station IBL) for physically based metallic reflections. Add your tone mapping and bloom pipeline to make emissive objects glow. Point-light values may need scaling for your renderer version. The meshes are open-top cutaway models with arch ribs; add ceiling panels for a fully enclosed first-person level.
6. Import `createHiveportAudio` from `systems/audio.mjs`, call `start()` after a user tap, and use `setZone(roomId)` and `sfx(name)` in the game's event callbacks. The audio is original procedural electronic music and synthesized effects, not recorded voices or licensed songs. OGG support depends on the browser; transcode to AAC if required.
7. `dialogue.json` supplies dialogue pools, player prompts and drink menu; connect it to the existing interaction UI. `serveDrink(npcId)` plays a prototype serve animation. The drink appears in the hand and is removed at the end; connect inventory transfer and bartending quest logic separately.
8. The two rigged K'Vetar GLBs retain 112 male and 28 female KHR_materials_variants combinations, respectively; selecting variants needs a compatible variant handler. Default loader material is used by the integration demo. The third character GLB is a violet translucent K'Vetar performer. The rigs use spatially estimated weights; refine hand grip, IK, foot planting and cloth/armor deformation in Blender before production. The clips are in-place and include Idle, Walk_InPlace, Talk, Reach_Grab, Serve_Drink, Drink_Sip, Toast, Dance, Brawl_Shove, Brawl_Recoil, Deescalate.
9. Ambient brawls are optional, rare two-character shove/recoil prototypes with path interruption. Security chime and de-escalate clip are available; actual guard dispatch, bystander gathering, player combat, damage and UI are not implemented. Integrate audio triggers, animations and event state with the game's existing systems. No violence is simulated outside those animations.

## Layout and limitations
96 x 44 m bounding rectangle, 4,224 m² gross footprint; central nexus height 12 m and side zones 6.5 m. Nine loadable zones. The private suite room contains six sleeping pods; individual suite walls and doors are not modeled. This is an implementable simplified layout, not a pixel-for-pixel recreation of the generated concept poster. The PDF plan and JSON are authoritative for the prototype meshes. Target points are examples; the real venue's advertised 600-person capacity is a lore figure, not a supported concurrent NPC count.

Collision avoidance is grid A* plus radius-aware local steering and exclusive destination slots. Tested in Node with 32 agents, 120 seconds, 42 accessible targets, no measured static/agent overlaps. That is not proof against every dynamic situation; test actual player collider, doors, dense crowd, movement scale and any additional furniture. Scene browser rendering and rig aesthetics were not tested in the user's live project. Models are procedurally constructed prototypes, not photorealistic production sculptures. Props and rooms have baked PBR material assignments; actual lighting and reflections are renderer-dependent.

Original concept poster is included as reference only; generated labels may not match the actual implementation. Use PDF page 1/JSON for dimensions and room locations.
