# Firefly WF-01 — cabin upgrade v1.1
Separate Pathfinder-class mission cruiser; SS Wayfarer mothership geometry/room layout unchanged. This supersedes the v1.0 Firefly replacement, not the v0.3.1 Wayfarer architectural kit.

## Install in a copy of v0.3.1
- Copy models/Firefly_WF01_HD.glb and models/Firefly_WF01_Mobile.glb to models/; if the host uses Firefly_Pathfinder_WF01.glb, point that reference at the new mobile model. Never load two ships or attach the old Firefly_Interior.glb.
- Replace the same-named assembled GLBs with patched/ versions. They embed the mobile Firefly at the original docking transform. Keep original v0.3.1 layout, jaw and other room models.
- Copy cabin_runtime.mjs and integration.mjs alongside the existing prototype adapter; for the live A-Frame game integrate cabin_runtime.mjs with its actual GLTFLoader, existing controls and mission state, rather than replacing the site. Call update(dt) per frame. The demo adapter intentionally does not grant boarding permission. Host must provide safe docked/landed and pressure state to allow hatch opening, and wire click/raycast handlers and player locomotion. getState returns optional NAV/SYSTEMS/MISSION/QUARANTINE/HATCH/COMMS dictionaries of key/value pairs, mode, and allowBoarding. Use activateDisplay(name) to dispatch UI events. Do not treat stand-by graphic values as telemetry. All six displays include embedded fallback screen art and named live-texture surfaces.
- Models are Y-up, forward -Z, engines +Z; inherited length 10 model units, not approved physical meters. Default gear deployed. The rear hull opening is deliberately compact (~0.96 x 0.75 model units); requires a crouch/crawl interaction, not a standing doorway. Hatch opens outward, beyond the closed bounding envelope. No swept clearance certification. The main single cabin has two pilot seats, three lockers, compact containment alcove, folding tray and aft benches, not extra rooms.
- Animations are named Landing_Gear_Deploy/Retract and *_Open/Close for Boarding_Hatch, Locker_1/2/3, Quarantine, Mission_Display, Work_Tray. Initial cabin mechanisms use closed/rest poses; work tray's rest pose is horizontal (opening clip rotates it toward its vertical lowered pose). Host must manage collision updates and interlocks. The animation adapter is a prototype, not tested in live WebGL.
- Embedded PBR texture maps: procedural brushed alloy, leather, deck grip, wall panel color/normal/metallic-roughness, six emissive displays. Actual model quality remains procedural, not photorealistic. Emissive strips do not cast light in standard GLTF; add runtime lights where needed. No production UV unwrap or physically simulated containment.

## Validation
See VALIDATION.json. Closed cabin vertices checked against analytic hull sections, with numerical tolerance. Animated motion, usable aisle width with open lockers, player traversal and collision, gear sweep and launch clearance still require testing. Original mothership fit issues are unchanged. Source scripts included for further editing; Python dependencies numpy, scipy, trimesh, shapely 2.1+, Pillow.
