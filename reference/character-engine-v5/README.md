# Wayfarer V5 — engine prototype
Supersedes V4. Keep V2/V3. No automatic installer: integrate deliberately, never run both motors. ES modules, meters, seconds, +Y up. Run `node --test test.mjs`.

Create Character(kind, position) for player/droid/cat/kvetar. Call tick(dt, input, world) once per frame; copy pos and yaw to actor root. Inputs x,z are world-space normalized directions; rotate local joystick by camera yaw first. run, jump, crouch, crawl, climb are booleans; up is signed vertical input. World must supply ground(position, profile) returning nearest reachable floor below or within step height (or null); stair and tread optional. Supply sweep(from,to,shape) returning true when clear; clear(position,shape) is a weaker fallback. Ground must distinguish decks and ceilings. Optional water(position), ladder(position), gravity, cameraCast(head,desired). Camera returns position only; host handles orientation, gyro and smoothing. Do not use existing fixed-y NPC renderer. NPC path follower should supply movement input and jump commands at tagged links; route() is a graph planner, not automatic scene extraction. StairLocks requires explicit release on exit/cancellation. Social V3 should reserve actors and call act(clip,duration) only after arrival; release on interruption. Animator accepts THREE.AnimationMixer and clips; missing clips fall back to Idle. footTargets returns target heights, not IK. surfaceAudio returns event keys, not sound assets.

Implemented prototype: acceleration, run, jump edge, gravity, landing, stair movement, collision hooks, crouch/crawl speeds, ladder/swim/zero-g movement modes, camera targets, action timing, animation crossfade adapter, graph routing. No new GLBs or actual animation clips; existing V2 clips may not match. No full capsule physics, vault/mantle, moving platforms, elevators, sliding, procedural rig IK, footstep cadence, mobile UI, audio files, paired animation alignment, or live game integration. Do not treat these as delivered. Crouch clearance, ladder exits, water boundaries and multi-deck collision require scene-specific testing. V4 navigation module retained for graph helpers; do not instantiate its old Motor. Species values are tuning defaults, not anatomical claims.
